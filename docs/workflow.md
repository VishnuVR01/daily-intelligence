# Daily Workflow

1. Fetch configured sources.
2. Parse feed entries.
3. Canonicalise URLs.
4. Deduplicate.
5. Save source metadata and original content.
6. Enrich/extract article text.
7. Classify by topic.
8. Rank by relevance/importance.
9. Create the morning edition.
10. Publish to the archive website.
11. Preserve every edition historically.
12. Later: deliver the edition by selected channel.

## Reliability rule

A failed AI model must never prevent raw news collection or corrupt source provenance.
