# Source Policy

## Preferred source order

1. Primary/official sources
2. High-quality wire services and established reporting
3. Specialist industry publications
4. Useful secondary analysis
5. Experimental/community sources

## Every stored article should preserve

- source name
- original URL
- canonical URL
- publication timestamp when available
- collection timestamp
- original headline
- original summary/content where permitted
- category
- processing status
- AI model/prompt metadata for generated fields

## Principle

AI-generated summaries are annotations, not replacements for source provenance.
